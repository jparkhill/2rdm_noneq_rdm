## The arc

The programme moved from "find a good cumulant reconstruction" to "find the constraint set that
fixes one", and then to a construction in which most of that set is structural rather than imposed.

**Extensivity is connectedness, derived not screened.** Cumulants are `log Z` of the moment
generating functional; for a product state `Z_AB = Z_A Z_B` gives `W_AB = W_A + W_B`, which yields
both extensivity clauses in one line. This is the coupled-cluster `exp` argument with the same
exponential: `gamma` is the group object, `lambda` the algebra object, and a wedge inside a
reconstruction of `lambda_k` is a product inside a logarithm. Theorem: additive under direct sum iff
the contraction diagram is CONNECTED. It retrodicts every extensivity measurement, including the
rank-4 trace-rule fit where all four connected structures took nonzero coefficients and all four
wedge structures came out exactly zero.

**Positivity is a property of the representation, not a constraint on the cumulant.** The exact
flow satisfies `Xdot = i(S^dag X - X S)` at every rank (derived: the H-sandwich terms cancel when
the Gram matrix is differentiated, and the two-body commutator refactors as a one-body operator
acting on a k-annihilated state). Hence `X = R^dag R` with `Rdot = -i R S` reproduces the flow while
keeping `X >= 0` structural. This is the **XR construction**.

**The G-transfer form and the ladder.** `Mat_{k+1}[(I,x),(J,y)] = (k+1) R_c(:,I)^dag G_xy R_c(:,J)`
with `G_xy = frak_a_x^dag frak_a_y` and `frak_a_x` the annihilation operator restricted to the
compressed spaces -- **the ladder**. At level 0 the ladder is `{a_x|Psi>}` and its Gram IS
`gamma_1`; at level k it is a matrix-valued `gamma_1`. A one-rung closure needs ONE ladder; the
tower was a derivation device only.

## RETRACTIONS from this session -- read these before trusting older commits

1. **Connectedness + trace + Lipschitz are NOT incompatible.** The trace-forced pole `a_r^{-1}` is
   cancelled exactly by `D`/`Q` Cauchy-Schwarz, which bounds every `lambda_2` element carrying index
   `r` by `O(sqrt(a_r))`. The error was screening a factor in isolation instead of the composite map
   on the N-representable manifold.
2. **Complete positivity is REQUIRED, not too strong.** CP contains reversible dynamics as its
   boundary (`Kossakowski = 0` is a Hamiltonian generator), and the exact `k = N` generator satisfies
   it. The `gamma*_CP` vs `gamma*_rate` gap of 10^3 is worst-case versus realised, not evidence
   against the criterion.
3. **The ladder's number condition does NOT imply the contraction identity** for a MODELLED ladder.
   Random Stiefel ladders satisfy `sum_x frak_a_x^dag frak_a_x = (N-1)I` yet give `tr Mat_2 ~ 16`
   against 12. It holds for the exact ladder only because that also satisfies CAR anticommutation.
   Automatic are `gamma_{k+1} >= 0` and exactness at `k = N`; NOT automatic are the contraction
   identity, the hole condition, and extensivity.
4. **Energy minimisation with D + contraction alone cannot fix the ladder** -- but adding Q rescues
   it (see below). The intermediate claim that the variational route was dead was too strong.
5. Two bad measurements, both discarded: the SVD-truncation "bound" (violates the trace, returns the
   one-body energy) and the first ladder optimiser (oracle error rose with `chi'`, impossible for a
   nested family).
